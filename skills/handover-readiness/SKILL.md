# Handover Readiness
## 체크
- [ ] Architecture/Interface 최신화
- [ ] 운영 Runbook
- [ ] 장애/알람 대응 기준
- [ ] 배포/Rollback 절차
- [ ] 계정/권한 인수 절차
- [ ] Known Issue/제약사항
- [ ] 운영 교육 및 연락체계
- [ ] 유지보수/지원 범위
- [ ] 산출물 저장 위치
## 판정
문서 존재가 아니라 실제 운영자가 수행할 수 있는지를 기준으로 판단한다.
