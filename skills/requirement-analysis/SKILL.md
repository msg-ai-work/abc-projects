# Requirement Analysis
## 절차
1. 요구의 목적과 사용자/시스템 주체를 확인한다.
2. 기능/비기능/운영/보안 요구로 분류한다.
3. 모호한 표현을 입력·조건·행동·결과로 구체화한다.
4. 기존 기능과 충돌/중복 여부를 확인한다.
5. Acceptance Criteria를 Given/When/Then 수준으로 정의한다.
6. 미결정 요구는 승인된 요구로 간주하지 않는다.
