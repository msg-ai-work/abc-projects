# Project Intake / Scope
## 절차
1. 해결하려는 비즈니스/운영 문제를 한 문장으로 정의한다.
2. In Scope와 Out of Scope를 분리한다.
3. 고객/당사/외부 이해관계자와 책임을 정리한다.
4. 일정, 예산, 보안, 기술 제약을 확인한다.
5. 성공지표와 완료조건을 정의한다.
6. 미확정 사항을 Assumption/Decision으로 분리한다.
## 출력
Project Goal, Scope, Stakeholder, Constraint, Success Criteria, Open Decision.
