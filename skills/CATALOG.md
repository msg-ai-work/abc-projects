# Projects Skill Catalog

| Skill | 목적 |
|---|---|
| `project-intake-scope` | 프로젝트 목적·범위·제외범위 정의 |
| `requirement-analysis` | 요구사항 구조화와 Acceptance Criteria 정의 |
| `architecture-impact` | 시스템/연계/보안/운영 영향 분석 |
| `integration-design` | 고객사·외부 시스템 연계 설계 점검 |
| `migration-plan` | 데이터/시스템 전환 계획 수립 |
| `test-readiness` | 통합/UAT/성능/보안 시험 준비도 점검 |
| `cutover-plan` | 오픈·전환 실행계획과 Go/No-Go 기준 |
| `rollback-plan` | 원복 조건·절차·데이터 정합성 계획 |
| `handover-readiness` | 구축 결과의 운영 이관 준비도 점검 |
| `risk-issue-management` | 프로젝트 Risk/Issue를 조치 중심으로 관리 |
