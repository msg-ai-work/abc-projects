# ABC Project Forge Roadmap

## Phase 1 - Core Orchestration
- project-config
- project-orchestrator
- 7 Sub Agents
- 기본 Template/Workflow
- 완료조건: 샘플 프로젝트가 01→05까지 문서 체인 실행

## Phase 2 - Quality / Harness Loop
- 단계별 Quality Gate 자동화
- risk-manager/project-reviewer
- 최대 3회 Rework Loop
- Evals 추가
- 완료조건: 의도적 결함을 올바른 이전 Agent로 되돌림

## Phase 3 - Worktree / PR Automation
- Worktree 생성/정리
- GitHub MCP
- PR Body 자동화
- 완료조건: 메인 작업공간을 오염시키지 않고 PR 생성

## Phase 4 - Jira / Confluence Integration
- Jira Intake/상태 동기화
- Confluence Evidence/결정 조회
- Secret은 개인 MCP 설정으로 분리
- 완료조건: Jira 키 하나로 프로젝트 Context 수집

## Phase 5 - Metrics / Continuous Improvement
- Evals, Gate pass rate, rework count, cycle time
- Skill 개선 PR 프로세스
- gstack benchmark/retro 개념을 프로젝트 수행에 적용
- 완료조건: AI Native SI 생산성 지표를 월별 비교 가능

GitHub Issue 번호는 Roadmap Issue 생성 후 본 문서에 연결한다.
